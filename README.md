# ⧉ Time Portal ⧉ – First HTML Web Test
Welcome to my first HTML web project! This is a simple but visually rich digital clock interface that displays the current time and date in Arabic, designed to feel like you're stepping into another world.

✨ Project Overview
This project started as a basic HTML and JavaScript test I created between 2022 and 2023. It displayed the current date and time using Arabic day and month names. It was my first time working with live DOM updates and date localization.

In 2025, I revisited the original concept and gave it a complete visual overhaul, turning it into a futuristic "Time Portal" with glowing neon effects, dynamic backgrounds, and custom fonts to make the user feel immersed in a sci-fi interface.

🚀 Features
Real-time clock (updates every second)

Arabic day and month names

Futuristic "Time Portal" interface

Responsive and centered layout

Glowing animated background

Uses Google Fonts (Orbitron) for a digital feel

🛠️ Technologies Used

HTML5

CSS3 (with animation and custom styling)

JavaScript (for dynamic time updates)

Google Fonts

🗓️ Timeline
Original version: Created between 2022 and 2023 (basic clock, minimal styling)

Updated version: Enhanced in 2025 (new design, animations, font, layout)

📁 Files
index.html – Contains the updated Time Portal code (2025)

💡 Why This Project Matters
This project is important to me because it represents my first step into web development. It shows how far I've come—from a basic static page to an animated and stylized experience. It’s a tribute to continuous learning and improvement.
